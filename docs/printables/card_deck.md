# Print-and-Play Event Card Deck

## Printing Instructions
* Standard Poker Card Size: 2.5" x 3.5" (63.5mm x 88.9mm).
* Format: 9 cards per 8.5" x 11" (Letter) or A4 page.
* Assembly: Print on standard paper and sleeve over bulk cards, or print onto 300+ gsm cardstock.
