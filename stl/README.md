# Miniatures & Terrain 3D Print Manifest

Print and scale specifications for *Attack of the Mutants (Miniatures Edition)*.

---

## Recommended Print Settings
* **Scale:** 28mm heroic scale (bases: 25mm round for infantry; 32mm–40mm for large bots/monsters).
* **Printer Type:**
  * **Resin (SLA/DLP):** Highly recommended for characters, mutants, and robots at 0.04mm–0.05mm layer height.
  * **FDM:** Recommended for barricades, smashed door tokens, and terrain walls at 0.12mm–0.16mm layer height with 15–20% infill.
